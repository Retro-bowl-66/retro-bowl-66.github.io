Inside Cell Machine: Program a tiny machine out of pushing cells

Sam Hogan's 2020 puzzle feels closer to engineering than to a traditional puzzle game. You are given a handful of cells with simple behaviors, some that push, some that rotate, some that create copies of their neighbors, and asked to assemble them into a contraption that delivers a target to its destination.

Gameplay overview

Each level gives you a set of cells to place on a grid. When everything is positioned, you press play and watch the machine run. Cells act according to strict, consistent rules, so results are predictable once you understand them. If the target reaches its goal, the level is solved; if not, you rearrange and try again.

Beginner's checklist

  • Test each cell type alone before combining them.
  • Run the machine often to check small ideas.
  • Watch the first few steps of a run closely to spot where things go wrong.

Strategy notes

Treat it like debugging. Run the machine, find the step where something deviates from your plan and fix only that. Generator cells are powerful but can create chaos, so place them carefully. Rotators change direction, which is often the missing piece when a pusher sends things the wrong way.

Final verdict

Smart, consistent and deeply satisfying when a contraption works. The visual style is minimal and the learning curve can be steep. A great choice for players who enjoy logic and programming-style puzzles.
