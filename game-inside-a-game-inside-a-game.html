Game Inside a Game Inside a Game... Online

Inside Game Inside a Game Inside a Game...: Puzzles stacked inside puzzles, like nesting dolls

Sam Hogan, who also made Cell Machine, built this puzzle on a concept that sounds like a riddle. What you are playing lives inside a second game, and that one lives inside a third. Getting anywhere means working out how the levels of nesting talk to each other, and how a change deep inside travels outward. Expect a mild headache, in a good way.

Gameplay overview

Each puzzle presents several nested layers. You can examine and interact with them, and what happens in one layer can change what is possible in another. The goal is to find the sequence that resolves everything at once. Expect plenty of head-scratching before the structure clicks.

Beginner's checklist

  • Study each layer on its own before thinking about connections.
  • Make one change and watch what it affects in the other layers.
  • Keep track of which layer you are currently working in.

Strategy notes

Think recursively. A solution in one layer often serves as a tool in another, so look for patterns that repeat across levels of nesting. When stuck, describe what each layer needs and see whether another layer can supply it. Patience pays off, because the logic is consistent once you understand it.

Final verdict

Inventive and genuinely mind-bending, it rewards players who enjoy abstract puzzles. It can be confusing and sometimes frustrating before the idea clicks. A great pick for fans of clever, unconventional puzzle design.
